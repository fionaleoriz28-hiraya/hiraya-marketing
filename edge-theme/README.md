# Hiraya Edge Theme

**From vision to visibility**

A minimal, soft pastel Microsoft Edge theme based on Hiraya Marketing's visual direction.

## Visual direction

- Soft off-white browser surfaces
- Sage/teal accent
- Light neutral inactive tabs
- High-contrast charcoal text
- Minimal, welcoming appearance

## Install locally in Microsoft Edge

1. Open **edge://extensions**.
2. Enable **Developer mode**.
3. Use **Load unpacked**.
4. Select this `edge-theme` folder.

The theme is a browser theme package, not a functional extension, so it requests no permissions.

## Publishing

Microsoft Edge Add-ons accepts themes. A store submission requires a packaged ZIP and listing assets. The package should be reviewed against the current Edge Add-ons requirements before submission.
